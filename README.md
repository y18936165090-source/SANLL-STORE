# 转角小卖部

使用 Three.js 与 Vite 制作的实时三维微缩街景。所有模型均由几何体生成，无需下载模型资源。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

在本机浏览器访问 `http://localhost:5173`；云环境中通过平台端口转发功能访问 5173 端口。服务器绑定 `0.0.0.0`。

## 构建与预览

```bash
npm run build
npm run preview -- --port 4173
```

构建输出为 `dist/`，可部署到静态网站托管服务。预览端口为 4173。

## 操作

- 鼠标左键拖动旋转，滚轮缩放，右键拖动平移。
- 触屏单指旋转，双指缩放和平移。
- 点击「白天 / 夜晚」切换环境和室内照明。
- 「街角小雨」开关控制动态雨丝，可与夜景组合。
- 「回到初始视角」重置镜头。

包含招牌、条纹遮阳棚、满货货架、饮料柜、收银台、果蔬摊、长椅、盆栽与路灯。支持响应式中文界面、阴影和阻尼镜头。需要浏览器支持 WebGL。字体使用可选 Google Fonts，连接不可用时自动使用系统字体，不影响场景运行。
